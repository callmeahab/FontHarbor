# Security reports

Report suspected vulnerabilities using the hosting platform's private vulnerability reporting feature when available. If it is not enabled, open an issue asking for a private contact channel without including sensitive details, malicious font files, credentials or an exploit.

Include the app version, macOS version, source URL if safe to share, and steps to reproduce. Font files are untrusted input parsed by macOS font frameworks. Keep macOS up to date.

The current pre-release code is the supported version. There is no published maintenance or response-time guarantee yet.
